LPHK 0.5.1

Read README.md for installation and use.
Windows prebuilt release: extract everything and open LPHK.exe.
Linux prebuilt release: extract everything and run ./LPHK.
MangoWM: first run bash install-linux-input.sh as your normal user.

The prebuilt archives include Python and application dependencies.
The source archive requires a development setup; see README.md.

Demo mode: click Demo mode in the app, then Play pads.
Soundtracks: edit a pad and choose Soundtrack... to set fade times.
